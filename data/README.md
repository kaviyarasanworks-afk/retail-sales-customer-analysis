## Data

### The raw dataset used in this project is Online Retail II, available on Kaggle:

🔗 https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci

### Why the raw CSV isn't in this repo

The raw file (~90+ MB) is too large to comfortably version in a standard GitHub repo. To use this project:

#### 1. Download online_retail_II.csv (or the equivalent file) from the Kaggle link above.
#### 2. Place it in this data/ folder as Raw_Data_online_retail_II.csv.
#### 3. Update the file path in notebooks/01_data_cleaning_eda.ipynb if needed.


If you do want the raw data versioned in GitHub, use Git LFS rather than a normal git add for files this size.
